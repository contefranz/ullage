SUSPECTED MISPRINTS / INCONSISTENCIES

1. Table IX(a) Altitude "10 430·765" ft. Read literally it is 10 430 765 ft (1717 n mi) or, with the raised
   dot as a decimal point, 10 430.765 ft (1.7 n mi); neither can be a deorbit altitude. The same digits
   read as 1 043 076.5 ft (171.67 n mi) fit everything else:
   - horizon dip at that altitude = acos(R_E/(R_E+h)) = 17.73 deg; 31.7 deg (5.4.1, pitched below the
     horizon) + 17.73 = 49.4 deg, vs "Retro attitude 49.3 deg";
   - with the table's 25262.5 fps / -1.04 deg pre-burn state, the pre-burn orbit is about 90 x 224 n mi, and
     an impulsive burn of the VIII(i) DeltaV (-191.20 along track, +203.05 down) gives entry at 400 000 ft
     at 25 835 fps / -1.74 deg, vs table IX(b) 25 850.3 fps / -1.759 deg.
   So the intended value is most likely 1 043 076.5 ft, with the group space and decimal point misplaced.
2. Table IX(b) reentry Longitude "98.83" has no minus sign, though the table uses signed degrees east
   (-153, -67.0) and the text (5.4.3) says 98.83 deg W. Propagating the deorbit point (11.89 N, -153,
   azimuth 60.61) along the great circle to 31.03 N and taking out 826 s of Earth rotation gives about
   -98 deg. So it should be -98.83.
3. Table I(a) Y_cg "=-.11 in": no leading zero, "=" and "-" run together, in a different typewriter font
   (looks like a typed-in correction). It reads as -0.11 in; flagged only for its odd form.
4. Table VIII(i) REFSMMAT row3 col2: speck before "0.41967032", not a minus. Orthonormality confirms "+".
5. Table I(b) SM RCS "Specific impulse" has no unit (other lines have ", sec").
6. Table I(d) concluded: viscosity unit printed "slug/fps" (should be slug/(ft-sec)); density symbol printed
   as "P" (rho) with subscript "inf SL".
7. Section 5.4.4 says figures 10-11 run "from the 400 000-ft altitude to reentry interface". In this document
   the 400 000-ft point IS the reentry interface, so the end point is probably meant to be something else
   (e.g. landing or drogue deploy). This is a wording inconsistency, not a number problem.
8. Section 5.1.5 (same page as 5.1.4; outside scope): "(03h20m00s g.e.t., the ..." has no closing parenthesis.
9. Formatting only: Table IX "25262.5" without a thousands space vs "25 850.3"; Table IX(a) longitude "-153"
   given as an integer; Table VIII(i) weight "25886.9" without a thousands space.

No digit in the requested values is uncertain: every value was read on zoomed crops (3x to 6x), and the
table cross-checks above (L/D = C_L/C_D, weight sum, Isp = F/mdot, REFSMMAT orthonormality, T_ig +
burn time = cutoff) all close.
